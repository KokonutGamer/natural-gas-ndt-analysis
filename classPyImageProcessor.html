Detailed Description

Concrete implementation of ImageProcessor that delegates execution to Python scripts.

Uses pybind11 to embed a Python interpreter, load external Python plugins, and dispatch image processing tasks to Python-based algorithms.

◆ PyImageProcessor()

PyImageProcessor::PyImageProcessor ( )

Constructor that initializes the embedded Python interpreter.

Acquires the Python Global Interpreter Lock (GIL), appends the project script directory to the Python path, loads the plugins, and binds the necessary Python functions and registries to C++ members.
